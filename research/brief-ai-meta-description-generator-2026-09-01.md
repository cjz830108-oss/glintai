## 2. 搜索意图与目标 SERP 形态

- **意图分类**：**Commercial（主）** + Transactional（辅）。搜索者已经知道 meta description 是什么，正在**找工具**并**评估哪个好**。
- **目标 SERP 形态**：
  - 顶部：交互式免费工具（Ahrefs / SE Ranking / Portent 的 widget）
  - 中部：`Best Meta Description Generators` 类 listicle
  - 下部：Yoast / Moz 等博客的定义与最佳实践文
- **Featured Snippet 机会**：**有**。建议：
  - `What Is an AI Meta Description Generator?` 小节用 **40–55 词**下定义 → 定义型 snippet。
  - `How Long Should a Meta Description Be?` 小节首句直接给答案（**150–160 字符 / 桌面约 920px**）→ 段落型 snippet。
  - 工具对比使用**表格** → 富媒体结果机会。

## 3. 竞品 Top 10 分析要点

| 维度 | 结论 |

| **字数基准** | 竞品多为 **1,400 – 2,200 词**（工具清单类偏短）。本文取 **2,100 词**，需靠「验证环节 + 评判标准」撑起篇幅而非堆工具数量。 |
| **必覆盖子话题（SERP 共识）** | ① 什么是 AI meta description 生成器<br>② 长度限制（字符数与像素宽度）<br>③ 每页唯一、避免重复/样板化<br>④ 匹配搜索意图 + 主动语态 + CTA<br>⑤ 关键词自然出现（非堆砌）<br>⑥ 生成后如何验证在 SERP 中的呈现<br>⑦ 免费工具对比<br>⑧ 常见错误（重复、过长、纯关键词、与正文不符） |
| **竞品内容差距（我们能在哪赢）** | 1. **验证闭环缺失**：竞品生成即结束，**无人解决截断问题**。我们用 `serp-preview.html` 提供「生成 → 预览 → 调整 → 发布」的完整闭环，这是本文最硬差异点。<br>2. **注册墙**：Ahrefs、SE Ranking、Writesonic 等需账号；我们 `no signup`。<br>3. **像素宽度讲不透**：多数竞品只说「150–160 字符」，**不说像素截断才是真实限制**；我们做专节讲透并给可操作方法。<br>4. **评判标准缺失**：竞品不给「如何判断 AI 生成的描述好不好」的标准；我们给一份可执行的检查清单。<br>5. **隐私**：竞品把页面内容上传云端；我们 `浏览器端运行、不上传`。 |
